# 分类稳定性测试报告

## 测试配置

- Prompt：`classification-prompt.md` v1.0
- 测试输入：12条，每条独立判定3次，共36次输出

## 重点观察

1. T11包含“春节”，但明确说明家庭自用且不是送礼，三轮均判为 `S01` 和 `M01`，没有误判为礼赠。
2. T07含普通场景词和专业参数，三轮均以专业创作者、8K和防护等级判为 `M04`。
3. T08的动机和场景明确，但人群只有年龄线索；三轮维持 `P01`，同时把该维度列为人工复核，防止把年龄直接等同身份。
4. T10没有目标用户、购买理由和使用环境，三轮均返回 `null/null/null`，整体置信度低于0.20，并请求补充信息。
