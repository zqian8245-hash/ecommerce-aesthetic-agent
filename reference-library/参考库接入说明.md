# classification视觉参考库接入说明

已接入22张案例图、27条视觉规则和18个分类标签。原始文件保留；新增案例观察、可迁移设计原则、视觉风险与自动匹配脚本。对外输入输出结构不变，总分≥8.5且每项≥8的严格标准不变。

本次是参考检索增强，不是训练模型参数。原库没有好/中/差标签，22张图全部保留“未评分、draft”状态。参考库的作用是让修改有具体方向，避免反复小改或统一套极简模板。实际达标率仍需独立测试，不能由接入本身保证。

## 使用顺序

1. 宿主提交原接口输入，scene_tags使用C模块分类ID或全名。
2. 自动匹配规则与案例，实际查看所选案例图、当前海报和原商品图。
3. 按六维量表独立评价，选择一个明确重构方向；不能把参考图中价格、功效、Logo带进新图。
4. 将观察保存为review，再生成固定评价JSON及独立改图提示词。
5. 制作新图并复评，未通过继续修改，达到既有停止条件时明确记录原因。

在Agent目录执行：

```powershell
node scripts/match-references.mjs --input task/input.json --category skincare --out task/reference-match.json
node scripts/evaluate.mjs --input task/input.json --review task/review.json --references task/reference-match.json --out task/round-01
```

category来自宿主实际看图后的内部品类判断，不能塞进外部输入。可选品类见index.json；不提供时只按场景匹配。脚本本身不理解图片、不调用模型，也不生成图片。宿主负责实际图像输入和迭代调度。

## 已校正的使用边界

- C-008的1100m、0.5mm、12支属于规格或数量，不能当作促销价格案例。
- C-018原风格分析尚未完成，新增观察仅用于视觉结构借鉴。
- C-021展示礼赠组合，参考时关注组合同框与信息分区。
- 原库没有银发人群专属案例，遇到P06不声称已覆盖。
- 来源商家、版权与人工审核状态保持原记录；本包用于研究参考，不复制商家素材发布。
