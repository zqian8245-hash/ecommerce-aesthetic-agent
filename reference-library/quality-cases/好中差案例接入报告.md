# 好中差案例接入报告

已接入用户案例17张：好9、中3、差5。原文件不改动；标签来源为用户目录，六维观察和修改方向由AI补充。

## 如何影响Agent

每次评价前按品类选取正、中、负例并实际看图，用于解释审美差距；制作时借正例的视觉关系、避负例的具体问题。固定输入输出及总分8.5、各项8的严格门槛不变。标签不直接换算分数。

12张为校准集、5张为暂保留集。全部在建库时已查看，暂保留集不是新盲测；后续独立验证需要新图。没有原商品素材、卖点与营销任务，不能对这些样例作正式通过判定。

## 这批案例揭示的偏好

- 喜欢有用途联系的场景、材质区分、清楚字级及有秩序的商品群。
- 反感模板展台、无功能悬浮道具、过多焦点和身份文字异常。
- 红色、3D与悬浮本身不低分：红色正例G-008和整齐3D正例G-006须防止错误概括。
- G-003/G-005/G-007是横幅拼图，先选子幅；G-009是战报，不能当作价格信息标杆。
- M-002可见Logo重复；P-001存在异常文案；M-003问题是模板陈列和信息节奏，不是拥挤。
