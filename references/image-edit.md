# 大幅重构与图像制作

当前业务输入包含两张图。图1为待评海报，可作为改前问题或必要信息参考；图2为原始商品图，是商品身份依据。不能以海报中的生成商品取代图2。

refine可以在原海报局部编辑；rebuild重排图文关系；redesign以原商品重新制作背景、网格、字体和光影，可放弃图1全部非必要风格。提示词明确所选强度和原因，不能一边要求重新设计一边要求所有区域不变。

优先使用原始商品素材和精确文字排版。在原商品无法可信保留的整图重绘工具中，生成结果只是候选，必须核验标签与Logo。可生成干净的背景/环境，再由制作模块放置真实商品和文字；主流程支持分层时采用此策略。不要用纯提示词宣称保证像素级保真。

如果运行宿主提供image_gen工具，先查看两张本地图像，再按实际工具schema引用原图。referenced_image_paths与num_last_images_to_include只能使用一种，覆盖全部目标/商品图。用生成的redesign-prompt作为prompt；透明背景按原素材和任务设置。工具参数以当前宿主定义为准。

不具备图像工具时完成固定评价JSON和内部提示词，制作状态记prompt_only。没收到新原始商品图时不可把旧618海报当商品母本，也不能伪造母本来实测。

原图尺寸若有实际测量则写入调度context.canvas，不增加业务字段。未给画布时保持海报实际宽高比，输出后检查真实尺寸/格式；无法精确导出则记录问题，不假报规格通过。

新图必须实际查看，再对照原商品、每条卖点、价格和确认Logo核验。任何受保护内容变化都令pass=false。输出图片留在版本目录，图片生成状态与统一评价JSON分开记录。
