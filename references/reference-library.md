# 视觉参考库：评价前检索，制作时提取原则

classification(1).zip 已原样解压在 assets/classification-source/classification。22张案例、27条规则、18个分类标签均保留来源记录。reference-library/index.json 是派生索引，visual-annotations.json 是AI视觉观察。原库案例全部为draft，没有好/中/差标签；不得当作已验证的高分标准，不构成模型参数训练。

评价前运行 scripts/match-references.mjs，读取原输入中的 scene_tags。支持分类ID、分类全名及无歧义的完整信号词，不根据数组位置猜测，不强行匹配未知或歧义标签。按三维、二维、单维、通用规则回退。内部可提供实际观察到的商品品类 --category（如skincare），它不是外部输入新增字段。没有匹配依据时不随机推荐图片。

宿主必须实际打开匹配案例图，再评价当前海报。文件路径不等于已看图。先完成独立的六维观察，再用案例检查是否存在更适合该人群与动机的表达；不能因为不像参考图就扣分，也不能照搬参考图的分数。参考库只提供视觉方向，评分门槛仍为总分8.5、每项8。

参考案例也有视觉风险。选择一条统一方向，最多使用少量兼容案例的构图、信息分组、字体层级、材质与光线原则，不把三张图所有风格堆在一起。跨品类案例只借布局和视觉关系，不借商品形状、卖点或功效。价格驱动场景允许醒目促销与较高信息密度，成熟人群也可采用明亮配色；审美标准不能变成统一米白极简模板。

规则里的色板、商品比例、禁止风格是场景建议，不能直接当硬性验收条件。色板只挑少量协调颜色。消费者关注权重不能替换美学六维权重。保留原商品身份、Logo、价格、卖点及活动事实；禁止复制参考商家的品牌、价格、规格、功效、优惠或假标签。

补充校正：C-008的大数字是规格/数量，并非价格；C-018原style_analysis未完成，使用新增视觉观察时明确它不是事实审核；C-021重点是完整礼赠组合。其他来源待核验记录保持待核验，不自动改成approved。

match结果为独立内部文件。evaluate.mjs 的 --references 可把匹配结果加入独立改图提示词；宿主在生成前仍须读取案例图。参考图不自动作为商品母本，不默认传入生成工具。唯一对外评价仍为既定JSON结构。

循环：查看新图→内容保护核验→六维重新评分→未通过时继续修改，直到达标或达到既有轮次/时间/停滞限制。禁止为了过线改阈值或抬高分数。新增参考库是否提升效果，需要另用未参与选图的测试海报验证。

通用聊天中使用完整可复制指令时，应一并附上选定案例图和匹配结果；仅复制文字无法读取此包内图片。
